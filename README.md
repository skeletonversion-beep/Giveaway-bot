# Telegram Giveaway Bot

## Giveaway
- Total prize: ₹150
- 1st: ₹100
- 2nd: ₹50
- Result: 12 September 2026, 10:00 AM IST
- 3 compulsory channels with join verification
- Entry required before referrals count toward ranking
- Ranking by valid referral count

## Railway variables
BOT_TOKEN = your Telegram bot token
ADMIN_ID = your Telegram numeric user ID

## Important
Add the bot as an administrator in all 3 compulsory channels so Telegram's getChatMember verification can work reliably.

Run locally:
pip install -r requirements.txt
python bot.py
